# 小程序头像 · 鸟巢剪影

「归巢」的小程序头像。深蓝底 + 琥珀色编织鸟巢，巢里两枚蛋。

| 文件 | 用途 |
|---|---|
| `nest-1024.png` | **上传用主图**（1024×1024，117KB）。微信后台会自己压到 144，直接传这张最稳 |
| `nest-512.png` | 分享卡 / H5 等较大尺寸位图 |
| `nest-192.png` | 中等位图（如需要 2x 场景） |
| `nest-144.png` | 微信要求的最小可用尺寸（144×144），备用 |
| `raw/nest-source.png` | 生成用源图（带渐变底与水印，未处理），仅作留档 |
| `../../scripts/make-logo.py` | 从源图重新生成上面四个尺寸的脚本 |

## 配色

- 底 `#002FA7`（品牌深蓝）
- 图形 `#F8B500`（品牌琥珀）

只在两个色之间做，没有渐变、没有描边，缩到 42px 仍然是「深蓝圆 + 亮色环 + 两个亮点」的形状。

## 上传到微信小程序

1. 微信公众平台（mp.weixin.qq.com）登录小程序账号
2. 左侧【设置】→【基本设置】→ 头像处点【修改】→ 上传 `nest-1024.png`
3. 提交后等审核，通常几个工作日；通过后部分场景有缓存，隔几小时才刷新

**规格限制**（微信官方）：正方形，144×144 以上，PNG / JPG，≤ 2MB；展示时四角会被裁成圆形或圆角，所以图形要居中留边——本图已按 86% 缩放进 1024 画布，圆形裁切不会切到巢的外缘枝条。

**注意**：小程序头像**每年只能改 5 次**，名字每年只能改 2 次。上传前先在手机上看一眼实际效果。

头像里不要出现二维码、电话号码、联系方式，也不要模仿微信官方样式的认证标识，这类会被驳回。

## 重新生成

改了源图或想调留边比例：

```bash
python scripts/make-logo.py                        # 默认读 raw/nest-source.png，86% 留边
python scripts/make-logo.py raw/nest-source.png 0.8  # 想留更多边就传更小的比例
```

需要 Pillow（`pip install Pillow`）。脚本会把源图里的非琥珀像素（渐变底、白色水印）统一压成深蓝，再用品牌色双色重绘，所以源图即使是带水印的 AI 生成图也能直接处理。

## 设计取舍

- **为什么是「巢 + 两枚蛋」而不是一只鸟**：头像在微信列表里只有 40px 左右，一只带翅膀的鸟在这个尺寸会糊成一团；巢是闭合的环形结构，缩放后仍能保持轮廓，蛋提供两个高对比的视觉落点。
- **为什么不用 SVG**：小程序头像只能传位图，而且这张图本身是位图生成的，硬转 SVG 描摹反而会丢掉编织的手感。仓库里的 `src/bird-art.js` 九型鸟剪影是另一套东西（结果页用），两者不通用。
