# 「归巢」城市定居测评 — 项目计划书

> 给毕业生和打工者一个"测一测你该定居哪个城市"的工具，像 MBTI 一样好传播，像买房顾问一样有信息量。

## 1. 项目概述

**一句话定位**：基于城市规划学经典理论 + 中国一二线城市真实政策数据的测评产品，帮助漂泊者回答"我该去哪座城市生活"。

**产品形态**：HTML 页面（MVP）→ 微信小程序（正式版）
**变现路径**：小红书 / 抖音内容引流 → 免费测评 → 付费深度报告 / 定居指南
**目标周期**：4-6 周出 MVP

## 2. 理论基础

测评的"灵魂"来自两本书，它们决定了产品的差异化——不是刻板的买房计算器，而是有人文底色的定居观。

### 2.1 《明日的田园城市》（埃比尼泽·霍华德，1898）

- **三磁体理论**：城镇、乡村、"城镇-乡村"各有引力。霍华德的答案是第三磁体——既有城市的机会与薪酬，又有乡村的低成本低压力。
- **转化为测评哲学**：用户的选择不是"北上广 vs 回老家"的二元题。测评帮他找到**属于他自己的第三磁体**——可能是"薪资 8 折但通勤 15 分钟的苏州"，可能是"有产业、有山水的成都"。
- **产品隐喻**：测评结果页叫"你的三磁体画像"，天然适合做社交传播卡片。

### 2.2 《城市发展史》（刘易斯·芒福德）

- **城市是人的容器**：城市的第一功能是让人安居，评判城市不能只看 GDP 与天际线，要看尺度、社区、文化、自然的关系。
- **反对"大城市崇拜"**：芒福德认为超大城市的无限扩张吞噬了生活本身。
- **转化为测评维度**：测评不只算经济账（薪资、房价），还要算**生活账**（通勤、气候、医疗、文化、离家距离）——这正是与市面上"城市吸引力排行榜"产品的差异点。

## 3. 目标用户与场景

| 人群 | 场景 | 痛点 |
|---|---|---|
| 应届毕业生 | 拿到多个 offer 选城市 | 只知道薪资差异，不知道政策、房价、落户 |
| 工作 1-3 年的"漂一族" | 是否换城市、回老家还是留一线 | 沉没成本焦虑，缺乏理性决策框架 |
| 已婚/备孕家庭 | 为子女教育、买房换城市 | 五险一金、学区、落户政策信息散乱 |
| 数字游民/远程工作者 | 低成本高宜居城市 | 缺乏系统对比工具 |

**共同痛点**：城市选择是人生前 10 年最重要的决策之一，但网上的信息要么是贩卖焦虑的"逃离北上广"，要么是冰冷的政策汇编，**没有人提供"个性化匹配"**。

## 4. 产品定义

### 4.1 测评流程

```
答题（约 5 分钟 / 32 题）→ 实时计算 → 三磁体画像 + Top 3 城市推荐 + 城市对比卡
```

### 4.2 输出物

1. **三磁体画像**：一个 MBTI 式的城市人格标签（如"机会优先型·闯将"、"生活优先型·园丁"、"平衡发展型·织巢者"），可保存为社交分享卡片
2. **Top 3 城市推荐**：每城给出匹配度百分比 + 推荐理由（薪资/房价/落户/宜居四个分项得分）
3. **城市对比卡**：任意两城的五险一金、购房门槛、落户难度、通勤中位数对照表
4. **付费深度报告**（变现点）：LLM 生成的个性化《XX 城市定居行动指南》——落户步骤、购房资格测算、人才补贴申领清单、前 90 天安家计划

## 5. 测评维度体系（核心）

### 5.1 用户侧（答题测的是"你"）

| 维度 | 权重 | 示例题项 |
|---|---|---|
| 事业雄心 | 20% | 愿意为薪资涨幅牺牲多少生活时间？行业天花板是否重要？ |
| 生活偏好 | 20% | 通勤 90 分钟换大房子，接不接受？气候/饮食/方言敏感度 |
| 家庭因素 | 20% | 配偶工作地？离父母多远可接受？子女教育优先级 |
| 经济基础 | 20% | 可动用首付预算？月供安全线？家庭能提供的支持 |
| 风险态度 | 20% | 愿意为落户/买房熬社保年限吗？接受政策变动风险吗？ |

### 5.2 城市侧（数据测的是"城市"）

| 维度 | 子指标 | 数据来源（采集阶段核实） |
|---|---|---|
| 经济机会 | 城镇平均薪资、本行业岗位密度、失业率 | 统计局、招聘平台公开报告 |
| 买房难度 | 房价收入比、首付中位数、限购门槛、房贷利率 | 官方限购政策、贝壳/安居客公开数据 |
| 落户与法规 | 落户门槛（学历/社保年限/积分）、购房资格年限 | 各市公安/人社局官网 |
| 五险一金 | 缴纳基数上下限、公积金比例（5%-12%）、医保报销比例 | 各市社保局年度公告 |
| 宜居条件 | 通勤中位数、三甲医院数、空气质量、教育资源、文化设施 | 交通报告、卫健委、环境公报 |
| 人才政策 | 应届生补贴、租房补贴、人才公寓 | 各市人才办公告 |

> ⚠️ 所有政策类数据**必须在数据采集阶段以 2026 年最新官方文件核实**，政策每年都在变（落户持续放宽是近几年的大趋势），产品要内置"数据版本号"，过期的数据宁可不上。

### 5.3 匹配算法

- **第一层（规则）**：硬性过滤——预算不足的城市直接排除（如首付预算 < 目标城市首付中位数下限）；户籍/社保年限明显不满足的购房项标记"暂不可行"。
- **第二层（加权匹配）**：用户五维得分 × 城市六维数据 → 归一化匹配度。
- **第三层（LLM 个性化）**：把用户答题向量 + 城市数据喂给 LLM，生成有"人味"的推荐理由与行动指南（不用手写模板词典，让模型组织语言；数值结论必须由规则层算出后传给模型，模型只负责解释与建议，**不得编造数字**）。

## 6. 城市库

- **一线**：北京、上海、广州、深圳
- **新一线**（首批入库 10 个）：成都、杭州、武汉、西安、苏州、南京、长沙、合肥、郑州、重庆
- **二线**（按流量需求逐步加）：昆明、青岛、宁波、无锡、天津…

MVP 先做 **8-10 个城市**（一线 4 + 新一线 4-6），每城约 40 个数据字段，人工采集 + 官方来源交叉验证。

## 7. 技术方案

| 阶段 | 方案 | 说明 |
|---|---|---|
| MVP（第 1-2 周） | 纯静态 HTML + 原生 JS/轻框架 | 问卷前端、规则计分、结果卡片渲染，零后端零成本，可部署 GitHub Pages 先跑通传播 |
| 二期（第 3-4 周） | 微信小程序 | uni-app/Taro 单码双端；用户授权、结果保存、支付 |
| 报告生成 | 后端函数 + LLM API | 只有付费报告走 LLM，按次计费，成本可控（单次 < ¥0.5） |
| 数据管理 | 城市数据 JSON 化入 git 仓库 | 政策更新 = 提交一次数据文件，可追溯 |

## 8. 商业变现

### 8.1 流量侧

- **小红书**（主力）：内容选题直接复用测评数据——《全国买房难度排行》《落户新一线城市要多久》《月薪 1w 在 10 个城市的生活质量》，笔记尾部挂测评入口；开通小红书店铺挂商品
- **抖音**：60 秒"测完哭了"系列短视频，评论区/主页导流小程序
- **冷启动钩子**：MBTI 式人格标签卡（三磁体画像）天生适合晒图，结果页带"你的城市人格"水印二维码

### 8.2 变现阶梯

| 层级 | 产品 | 定价（试定） |
|---|---|---|
| 免费 | 测评 + 三磁体画像 + Top 3 城市 | ¥0（引流） |
| 轻付费 | 城市对比完整报告 + 数据表 | ¥9.9（决策门槛低，跑转化率） |
| 主动付费 | 《目标城市定居行动指南》（LLM 个性化） | ¥29.9-49.9 |
| 高客单 | 1v1 城市选择咨询 / 定居社群 | ¥199+（验证需求后做） |

**核心逻辑**：免费层做传播，¥9.9 验证付费意愿，LLM 报告是毛利最高的自动交付品，咨询是人工天花板。

## 9. 竞品与差异化

| 竞品类型 | 例子 | 缺陷 | 我们的差异 |
|---|---|---|---|
| 城市排行榜 | 各类"新一线城市榜" | 面向城市营销，不针对个人 | 个性化匹配 |
| 房产工具 | 贝壳等选房工具 | 以卖房为目的，无"该不该来"决策 | 中立、以人为中心 |

| 付费咨询 | 知乎/小红书博主 | 贵、非标、不可规模化 | ¥9.9 起的标准化产品 |

## 10. 里程碑

| 阶段 | 时间 | 交付物 |
|---|---|---|
| M1 理论与题库 | 第 1 周 | 32 题题库定稿、计分模型、城市数据 schema |
| M2 数据采集 | 第 1-2 周 | 8-10 城完整数据 JSON（全部带官方来源链接） |
| M3 HTML MVP | 第 2-3 周 | 上线可测、可分享卡片 |
| M4 引流验证 | 第 3-4 周 | 小红书 10 篇笔记、观察自然流量与完测率 |
| M5 小程序 + 支付 | 第 5-6 周 | 微信小程序、¥9.9 报告跑通闭环 |

**MVP 验证指标**：完测率 > 60%、分享率 > 15%、¥9.9 转化率 > 3%。达不到就改题库/卡片，不加功能。

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 政策数据过期/出错 | 数据带来源链接与更新日期；免责声明"以官方最新政策为准" |
| 微信小程序审核（测评类目） | 定位"工具/资讯"而非"心理测试"；避开敏感话术；备选 H5 |
| 引流平台限流 | 内容以"城市数据科普"为主体，测评入口放评论区/私信 |
| 被抄袭 | 壁垒在持续运营的城市数据库 + 内容账号，不在代码 |
| LLM 报告质量不稳 | 数值由规则层计算锁定，LLM 只做解释；输出走结构化校验 |

## 12. 与我现有管线的协同

## 13. 学术脉络：2000 年至今两本经典的引用与探讨

两本书在中文学术界的生命力于近 20 余年持续在线：田园城市理论沿着"中国化诠释 → 城乡统筹 → 公园城市"的路径被反复重读，芒福德研究则在 2014 年之后形成国家级课题与专著。本节梳理其脉络，也说明"归巢"测评的理论坐标系站得住。

### 13.1 《明日的田园城市》：从经典重读到"公园城市"

| 时期 | 学术动向 | 代表成果 / 实践 |
|---|---|---|
| 2000s 初 | 理论本源重读：把霍华德还原为"社会改革家"而非"形态设计师"，辨析田园城市 vs 花园城市、资金机制（土地社区所有） | 金经元译本（商务印书馆）持续被引；大量期刊论文讨论"田园城市的精髓是城乡一体、本质是社会改革" |
| 2009-2012 | 地方实践高潮：成都确立"世界现代田园城市"定位，催生成规模实证研究 | 景观格局优化（RS/GIS 源地-廊道识别）、绿色屋顶固碳测算、经济与大气环境承载力协调分析、"现代田园城市：统筹城乡发展新模式"（成都试验区背景）等学位论文与期刊文章 |
| 2013-2019 | 上升为国家话语：田园城市与新型城镇化、城乡统筹、生态文明对接 | "田园城市思想对新型城镇化的角色定位""英国小城镇城镇化的启示"等；人民论坛《田园城市思想的内涵及其当代价值》指出其人人平等、生态健康目标仍未实现 |
| 2020 至今 | 理论重构与范式转移：疫情后大都市危机重提，"公园城市"成为田园城市的当代中国形态 | 西南大学学报《从"田园城市"到"公园城市"》把田园城市确认为公园城市的思想起源；中国城市规划网《新兴田园城市：移动互联网时代的城镇化理论重构》提出"规模悖论"解释田园城市实体空间失败、以"流乡村/流城镇"（虚拟集聚）实现"第三磁体"——这恰是"归巢"测评"机会与生活可以不二选一"命题的学术注脚 |

**关键学术发现（对本项目的直接启示）**：
1. **"规模悖论"是学界共识**——集聚规模效应与田园环境效应在实体空间难以双优，解释了为何一线拥挤与"逃离北上广"并存；测评把"虚拟集聚/远程工作"纳入风险态度与事业维度的权重，是有学术依据的差异化。
2. **田园城市在中国是"方法论"而非"形态学"**——多篇论文强调其精髓是城乡一体与社会改革，测评城市维度中的"人才政策/城乡融合"指标与之呼应。
3. **公园城市（成都 2018 提出）已写入国家战略**——"人、城、境、业"融合的评分思想可反向借入"宜居条件"子指标权重。

### 13.2 《城市发展史》：从译介到国家社科基金专题

| 时期 | 学术动向 | 代表成果 |
|---|---|---|
| 1989-2000 | 译介奠基：倪文彦、宋俊岭译本（中国建筑工业出版社）出版即售罄，成为城市科学界必读书 | 15 年后（2005 前后）出第二版；宋俊岭另有译介文章系统介绍芒福德生平与"城市是人类文明的容器与磁体"命题 |
| 2000s | 城市史学科化的引用底座：芒福德"容器/磁体""城市是文化的归极"成为城市史、城市规划论文的标准理论支点 | 《城市的迷途是文化的隐匿——读〈城市发展史〉》等书评型论文；杨长云《通往城市史之路》梳理芒福德以"容器与磁体"贯穿城市史叙事的内在理路 |
| 2014-2020 | 国家级专题研究：上海师范大学陈恒主持国家社科基金项目《刘易斯·芒福德城市理论研究》（14BSS003），成果为同名专著，课题组成员含宋俊岭等 | 全国哲学社会科学工作办公室专栏总结：芒福德"生态城市、区域城市、人文城市"三大理念；"容器/磁体"被用于古埃及城市功能等实证研究 |
| 2020 至今 | 人文城市思想的现实回归：城市更新、人民城市理念下，"城市首先是人的容器"被频繁征引 | 博士论文《刘易斯·芒福德的城市史观》（附 80 年代以来国内芒福德研究附录）系统盘点；澎湃《市政厅》专栏以"磁体与容器"重释城市功能，进入公共讨论 |

**关键学术发现（对本项目的直接启示）**：
1. **"磁体先于容器"**——芒福德认为城市最原初的功能是吸引人的"磁体"（精神与文化聚集），而后才是养育人的"容器"；测评结果页的"三磁体画像"命名因此不只是借用霍华德的修辞，而是踩在两本书共有的"磁体"概念上。
2. **对"特大城市神话"的批判已被学界接受并局部验证**——特大城市的无限扩张被认为吞噬生活本身（第 17 章命题），测评对超大城市不加分、对"生活质量/通勤/医疗"加权的设计与此一致。
3. **"人文城市"是持续 20 年的评价框架**——从书评到国家课题，学界始终用"人是城市的目的"评判城市；这正是"归巢"与 GDP 排行榜类产品的根本分野，也是内容营销时最有力的故事线。

### 13.3 小结

- 两本经典在 2000 年后的中文学术场域一个走向**实践化**（成都、琼海、太仓的田园/公园城市实验），一个走向**理论化**（国家社科基金专题、城市史学科化），共同支撑了"以人为尺度评价城市"的当代合法性。
- "归巢"测评的理论差异化因此有据可依：霍华德给了我们**三磁体的选择框架**，芒福德给了我们**生活账优先的指标哲学**，而 2020 年后的"新兴田园城市/流空间"研究甚至暗示了测评的目标人群——可在流空间中自由选址的数字游民与新一代毕业生。
