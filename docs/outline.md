## 1. 五维用户画像定义

每个维度：操作化定义、测量目标、计分区间、典型题目方向、反社会期许设计。

### 1.1 事业雄心（Ambition）

| 项 | 内容 |
|---|---|
| 操作化定义 | 个体对职业成长上限、行业天花板、权力/声望/收入增长的主观权重 |
| 测量目标 | 判断用户应为"机会密度"支付多大生活成本（通勤/住房/城市规模） |
| 计分区间 | 1-100；高分=机会优先（一线/新一线加权），低分=生活优先（宜居/低成本加权） |
| 题目方向 | 愿意为涨薪牺牲的生活时间、行业集中度是否重要、对"一眼望到头"的接受度、创业意愿 |
| 防偏差设计 | 不直接问"你有事业心吗"（社会期许会拉高），改问行为取舍："如果 A 城市薪资高 30% 但通勤 90 分钟，B 城市薪资低 20% 通勤 20 分钟，你选？" |

### 1.2 生活偏好（Lifestyle）

| 项 | 内容 |
|---|---|
| 操作化定义 | 个体对气候、饮食、文化、节奏、自然环境的敏感度与偏好的稳定性 |
| 测量目标 | 判断用户对"宜居条件"维度的敏感度——同样的城市数据，敏感者权重放大 |
| 计分区间 | 1-100；高分=强偏好（宜居权重上调），低分=强适应（宜居权重下调） |
| 题目方向 | 对湿冷/干燥的忍耐度、方言区融入意愿、周末活动类型（户外/社交/宅）、对"慢城市"的向往度 |
| 防偏差设计 | 用"过去一个月你做了几次 X"的行为频率代替"你喜欢 X 吗"的态度陈述 |

### 1.3 家庭因素（Family）

| 项 | 内容 |
|---|---|
| 操作化定义 | 家庭生命周期阶段（单身/已婚无孩/备孕/有学龄子女/赡养老人）对定居决策的约束强度 |
| 测量目标 | 判断教育、医疗、离家距离、配偶就业联动四个子项的权重 |
| 计分区间 | 1-100；高分=强家庭约束（教育/医疗/离家距离权重上调） |
| 题目方向 | 婚育状态与计划、父母所在城市、可接受的探亲往返时间、子女教育资源优先级、配偶就业灵活性 |
| 防偏差设计 | 客观题占比高（状态类事实题），态度题少——家庭维度事实比观点重要 |

### 1.4 经济基础（Economy）

| 项 | 内容 |
|---|---|
| 操作化定义 | 当前可支配资产、收入现金流、家庭支援能力、负债安全线 |
| 测量目标 | 生成硬性过滤参数（预算下限/上限、月供安全线），同时影响"买房难度"维度的权重 |
| 计分区间 | 1-100（高分=资金充裕），但**更重要的是原始数值**——直接进过滤规则 |
| 题目方向 | 可动用首付预算区间、税后月收入、月供占收入比的安全线、家庭可支援额度 |
| 防偏差设计 | 用区间选择（如 20-30w/30-50w/50-80w/80w+）代替精确数字输入，降低填写阻力与虚报 |

### 1.5 风险态度（Risk）

| 项 | 内容 |
|---|---|
| 操作化定义 | 个体对政策变动、职业不稳定、定居沉没成本、远程工作可行性的容忍与规划 |
| 测量目标 | 判断用户是否适合"政策红利型"城市（如人才补贴高但政策变动快的城市）与远程/数字游民路径 |
| 计分区间 | 1-100；高分=高容忍（可为补贴/机会承担政策风险），低分=求稳（成熟政策城市加权） |
| 题目方向 | 对"落户政策每年都在变"的焦虑度、远程工作可行性、是否愿意为补贴熬社保年限、定居决策的可逆性认知 |
| 防偏差设计 | 情景题代替态度题："如果目标城市明年取消你符合的落户条件，你会？" |

## 2. 三磁体画像分型体系

基于霍华德"城市/乡村/城市-乡村"三磁体 × 用户五维得分，产出**可传播的画像标签**。

### 2.1 分型逻辑（9 型，3×3）

```
            事业雄心
            低 ──────→ 高
生活    低 │ 织巢者   平衡家   开拓者
偏好    中 │ 守望者   织网者   闯将
        高 │ 园丁     回归者   游牧者
```

| 画像 | 维度组合 | 一句话画像 | 典型城市倾向 |
|---|---|---|---|
| 开拓者 | 事业高 + 生活低 | "先征服一座城，再考虑生活" | 北上深 |
| 闯将 | 事业高 + 生活中 | "机会是主线，但不打算押上全部" | 杭/蓉/苏 |
| 游牧者 | 事业高 + 生活高 | "要事业也要山海，哪里值得去哪里" | 昆明/大理/远程友好城 |
| 平衡家 | 事业中 + 生活低 | "稳定压倒一切，城市为职业服务" | 广/汉/郑 |
| 织网者 | 事业中 + 生活中 | "事业生活四六开，人情味不能少" | 长/蓉/宁 |
| 回归者 | 事业中 + 生活高 | "父母在不远游，但县城回不去" | 家乡省会/强二线 |
| 织巢者 | 事业低 + 生活低 | "房子是巢，能住就行，别谈理想" | 低成本宜居城 |
| 守望者 | 事业低 + 生活中 | "生活大于事业，但要个像样的家" | 佛山/无锡/芜湖 |
| 园丁 | 事业低 + 生活高 | "城市是花园，我只是来种花的" | 昆明/珠海/厦门 |

> 家庭/经济/风险三维不作为分型主轴，而是作为**约束修正器**：同样"闯将"画像，家庭约束高的推荐不同城市组合。

### 2.2 画像文案基调

每型配 3 句话：一句"你是谁"（共鸣）、一句"你的矛盾"（扎心）、一句"你的路"（方向）。LLM 生成 + 人工润色，禁止鸡汤腔。

## 3. 城市匹配规则

### 3.1 硬性过滤（先于加权计算）

| 规则 | 逻辑 | 来源维度 |
|---|---|---|
| F1 预算过滤 | 用户首付预算 < 城市首付中位数下限 × 0.8 → 该城标记"预算紧张" | 经济 |
| F2 购房资格 | 用户社保年限 < 城市购房资格要求 → 标记"暂不可购（需 X 年）" | 家庭/风险 |
| F3 落户可行性 | 用户学历/年龄不满足该城最低落户通道 → 标记"落户难" | 家庭 |
| F4 行业适配 | 用户所在行业在该城岗位密度 < 阈值 → 匹配度上限 -15 | 事业 |

### 3.2 软性加权公式

```
城市匹配度 = Σ(用户维度敏感度 S_i × 城市维度得分 C_ij × 动态权重 W_ij) / 100

S_i   = 用户第 i 维答题得分（归一化 0-1）
C_ij  = 城市 j 在第 i 维的归一化得分（0-100，P2 采集后映射）
W_ij  = 动态权重：基础权重(0.2 每维) × 用户敏感度修正 ± 家庭/风险约束修正
```

**动态权重示例**：用户"生活偏好"得分 90（高敏感）→ 宜居条件权重从 0.2 升到 0.32，经济机会从 0.2 降到 0.14。

### 3.3 输出排序

Top 3 城市 + 1 张对比卡（用户可自选 2 城对比）。每城输出：匹配度%、四维分项得分（机会/买房/落户/宜居）、一句推荐理由（LLM 解释层生成，**只解释已算出的数值，不生成新数字**）。

## 4. 输出物清单

### 4.1 免费层（传播层）

1. **三磁体画像卡**（可分享图）：画像名 + 3 句话 + "去测测你是哪种"二维码
2. **Top 3 城市推荐**：匹配度% + 理由一句话
3. **城市对比卡**：任选 2 城，对比 6 维数据表

### 4.2 付费层（¥9.9 深度报告）

1. 用户完整五维雷达图 + 画像深度解读
2. 目标城市《定居行动指南》：落户步骤、购房资格测算、人才补贴申领清单、前 90 天安家计划
3. 备选城市"退出方案"（如果首选失败）
